# 需求

实现方式、阈值与实测依据见 [子系统参考](subsystems/README.md)。

## 目标

在 macOS 上，将 **网易云音乐** 和 **Apple Music** 的歌词同步显示在 **状态栏、桌面悬浮窗、桌面组件和独立舞台窗口**，并在独立状态栏项里实时显示 **CPU、内存、SoC 温度与上下行网速**。
自己实现，可以参考开源方案里有价值的做法，但不直接使用它们。

## 功能

| 需求 | 验收标准 | 状态 |
| --- | --- | --- |
| 跟随 Apple Music | 识别当前歌曲；播放、暂停、切歌、拖动进度后，歌词在 2 秒内跟上 | 已实现；完整播放流程待验证，资料库为空 |
| 跟随网易云音乐 | 识别当前歌曲；播放、暂停、切歌后歌词跟上，网易云窗口在后台时同样有效 | ✅ |
| 网易云拖动进度后同步 | 拖动后约 2 秒内跟上，误差 ≤ 1 秒，之后继续收敛 | ✅ 实测依据见 [网易云来源](subsystems/netease.md) |
| 状态栏歌词 | 显示当前行，支持 180 / 260 / 340 pt 宽度上限与长句截断；关闭歌词且开启监控时释放该状态栏项空间 | ✅ |
| 状态栏系统监控 | 独立紧凑状态栏项显示网速及 CPU / RAM / 温度（支持切换为 20 pt 仅三色柱模式、柱状图彩色/单色显示、自定义采样间隔与告警阈值）；点击展开随主题适配的 Liquid Glass 详情面板，含趋势、核心/GPU 负载、Top 10 进程与确认后结束进程、内存构成、热力分布、功耗和风扇；关闭监控后停止定时采样 | ✅ 默认开启；见 [系统监控](subsystems/monitor.md) 与 [界面](subsystems/ui.md) |
| 桌面悬浮歌词 | 置顶、跨桌面与全屏可见，不抢焦点；无背景双行文字，支持 22 / 26 / 30 pt 字号与副句模式（翻译优先 / 仅翻译 / 单行主句）；默认鼠标穿透，按住 `⌘` 移入唤醒霜光玻璃卡片与控制栏（含曲目信息、±0.5s 偏移微调、播放/暂停、锁定与隐藏），松开后在卡片内仍可交互、拖动或双击切下一首 | ✅ |
| 桌面组件 | 位于 App 窗口之下、桌面图标之上；采用封面流光与霜光玻璃材质，未播放时收起为可选择播放器并开始播放的紧凑卡片，播放时展开封面、曲目、进度、双行歌词及播放/暂停、关闭按钮；支持双击切下一首、拖动和位置保存 | ✅ 默认关闭 |
| 演示舞台模式 | 独立圆角、可缩放窗口，可最大化至当前屏幕可用区域并还原；封面取色背景、「流光」与「描金」两种律动风格、星火开关和黑胶间奏；悬停显示四角控制项，支持双击切下一首，关闭后停止渲染 | 已实现，默认关闭；性能待验证，见 [舞台模式](subsystems/stage.md) |
| 桌面配置中心 | 左右分栏窗口（左侧「播放器 / 监听」双 Tab 导航，右侧分组配置卡片）；可通过重新打开 App、右键菜单「配置中心… (`⌘,`)」或监控弹窗底栏唤起；窗口关闭后卸载内部视图树，保持后台零开销 | ✅ |
| 逐字歌词 | 有网易云 YRC 数据时逐字填色，无逐字数据时逐行显示；长前奏、演职员行后或长间奏期间显示呼吸指示器并预告下一句 | ✅ |
| 翻译 | 有翻译时显示在对应行 | ✅ |
| 手动校正 | 菜单、悬浮歌词唤醒栏或配置中心里可让歌词提前或延后 0.5 秒，换歌后重置 | ✅ |
| 菜单与重开入口 | 状态栏被刘海挤掉时，可右键桌面歌词、桌面组件或舞台窗口弹出主菜单，或再次打开 App 直接唤起桌面配置中心 | ✅ |

## 明确不做

| 事项 | 原因 |
| --- | --- |
| WidgetKit 小组件 | 刷新频率由系统控制，无法实现实时歌词 |
| 借系统二进制的授权读 MediaRemote | 属于绕过系统权限，见 [代码规范](code-standards.md) |
| 为没有逐字数据的歌估算逐字填色 | 用户未采纳；舞台无 YRC 时的文字入场节奏不作为逐字同步承诺 |
| 拖动后用滚轮手动对齐 | 已能自动同步，无需此交互 |

## 后续方向

## 待验证

- Apple Music 播放中的完整流程：当前资料库为空，不为测试添加歌曲。
- Liquid Glass 的实际视觉效果：现有证据仅覆盖离屏布局，尚未验证实际屏幕呈现。
- 舞台模式在真实逐字播放、两种风格和开关窗口场景下的 CPU 与隐藏后开销；桌面双窗口的已有性能结论不覆盖舞台模式。
